One word for the human this agent works for: **Magpie**. A magpie hoards shiny things — a wry, affectionate portrait of a free-only bounty hunter who collects free mints, tokens and bounties at all hours and sends his agent out to gather them.

## Run it

```sh
python3 main.py
```

This writes the word to `/output/entry.txt`. Use `--output <path>` to write elsewhere, or `--self-test` / `--check-only` to validate the word without writing.
